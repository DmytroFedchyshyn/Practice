# Practice

Salesforce practice projects and exercises. Each project is self-contained in its own folder, with its own Salesforce DX project, documentation and tooling, so it can be read, deployed or moved to a repository of its own on its own.

## Projects

| Project | What it is | Status |
|---|---|---|
| [agentforce-distributor](projects/agentforce-distributor) | Agentforce and Data Cloud reference build: a partner portal where partners ask an agent about orders, stock and returns | In progress: agent active, Data Cloud next |

## Exercises

[exercises](exercises): classic algorithms and Gang of Four design patterns in Apex, and Trailhead exercises, as one Salesforce DX project with a package directory per topic.

## Layout

```
projects/<project>/     one folder per project, with its own sfdx-project.json, docs and tooling
exercises/              small exercises, one Salesforce DX project
```

All companies, people and data in this repository are invented.
